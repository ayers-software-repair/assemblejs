# @assemblejs/core

The server that composes pages out of assemblies, and the types the contract is written in.

An assembly is a piece of a page written in one UI framework: whole, addressable, and renderable
on its own. A page is a route that places assemblies. Some of them live in this project and some
live on other servers, and the composer treats both identically.

See <https://ayers.repair/assemblejs/>.
