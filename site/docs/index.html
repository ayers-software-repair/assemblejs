The model

assembly
A piece of a page written in one UI framework: whole, addressable, renderable on its own. Nested inside another it is a subassembly. Given a URL, it lives on another server and nothing else about it changes.
page
A route that renders a template which places assemblies. A page is an assembly that has a route.
service
A function that runs on the server before an assembly renders and returns its data. The same function answers the assembly's data endpoint, so the two can never disagree.
api
A route that serves data to anyone.

The contract

Three endpoints per assembly
Content, data and manifest. Any server in any language can serve an assembly by answering those three correctly, which is what makes a second team cost nothing.
Nothing crosses to the browser but JSON
A named projection of six fields. Not your request, not your headers, not your cookies, and never another assembly's rendered bytes.
