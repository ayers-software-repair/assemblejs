Installing

AssembleJS needs Node 22 or newer and nothing else. There is no global install: the command comes with the project it creates.

Make a project

npm create @assemblejs my-app
Writes a project that runs, with one assembly in it. Use pnpm or yarn if you prefer; the generated project does not care which one made it.
cd my-app && npm install
Installs the framework and the one renderer your first assembly uses. A React team does not install Vue, because each renderer is its own package.
npm run dev
Starts the server and prints the address. Edit an assembly and the page reloads.

Add it to a project you already have

npm install @assemblejs/core
The runtime. It brings a web server and nothing else; there is no bundler in it, and a built server starts with plain node.
npm install -D @assemblejs/cli
The command that scaffolds assemblies and builds the project. It is a development dependency: production runs the build, not the command.
