Documentation / Create your first application

Create your first application

Run an AssembleJS page, then add the frameworks you want to use.

Before you start

Install Node.js 22 or newer. The project includes its own CLI; no global installation is required.

01Create the project

npm create @assemblejs@latest my-app
cd my-app
npm install
npm run dev

Open the address printed by the development server.

Check

The generated page opens at the server’s printed address.

02Change an assembly

Open src/assemblies/hello/hello.html, change its visible text and save. The development server rebuilds the page.

Check

The page shows your change. The assembly lives separately from the page that places it.

03Add your framework

For a Svelte assembly:

npx assemblejs add assembly counter --renderer svelte
npm install @assemblejs/renderer-svelte svelte

Place it in src/pages/home/home.html:

<assembly name="counter"></assembly>

Continue with the page-building tutorial or a guide for React, Vue or Svelte.

If the page will not start

Check your Node.js version, run the commands from the project directory and read the terminal error. Run npx assemblejs check to check the project’s structure.
