## AssembleJS 1.0.0-next.0

One page from every framework: each piece written in the framework its author knows, composed on the server. Free and open source.

**The server** (`@assemblejs/core`) composes a page from assemblies, in your project or on another server, each with a deadline and a fallback, and hydrates them in the browser.

**The renderers** are one package for each framework, React, Preact, Vue, Svelte, Solid and Lit, and one for the template languages EJS, Handlebars, Markdown, Nunjucks and Pug.

**The command line** (`@assemblejs/cli`, and `npm create @assemblejs`) makes a project, adds an assembly to it, runs, builds, checks and weighs it, and writes the directory that runs it anywhere Node does.

**The agent surface** (`@assemblejs/mcp`) is an MCP server that every new project installs and registers, with an `AGENTS.md` beside it, so an AI agent knows the framework before it writes.
