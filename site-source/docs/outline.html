Documentation / Inspect a page

See how a page is composed

Find each assembly, the server that supplied it, and when it became interactive.

Enable the outline

Add outline: true to your assemblejs.config.ts:

import { defineConfig } from "@asmjs/core";

export default defineConfig({
  outline: true,
});

Start your application and press Outline in the corner of a page. Each assembly gets a box showing its identity, origin and timing. Press it again to return to the page.

Check

The boxes follow the assemblies on the page, including assemblies supplied by other servers.

Try a complete application

Pour & Grind is a shop composed from four teams’ servers: shop, catalog, reviews and fulfilment. Its views use React, Vue, Svelte, Preact, Solid, Lit and template renderers.

From a checkout of the repository, run:

pnpm install
pnpm build
pnpm --filter "@asmjs/example-market-*" build
node examples/market/start.mjs

Open http://127.0.0.1:4700/. Browse a shelf, open a product and switch on Outline. The product page draws twelve assemblies from three servers.

Stop the example, then run node examples/market/start.mjs shop catalog fulfilment to leave out reviews. The product still loads and reports that reviews are unavailable. The example’s README explains its routes and current framework boundaries.
