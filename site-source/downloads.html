Downloads

AssembleJS is distributed through npm. Use Node.js 22 or newer.

Create an application

Start with a working page and add the frameworks you need.

npm create @assemblejs@latest my-app
cd my-app
npm install
npm run dev
Installation guide

Add AssembleJS to a project

Install the runtime, CLI and the renderers your application uses.

npm install @assemblejs/core
npm install -D @assemblejs/cli
